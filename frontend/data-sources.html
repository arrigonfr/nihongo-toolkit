Category membership can overlap. Kokuji is recorded only when explicitly marked by KANJIDIC2; an absent marker means unknown, not proof of non-membership. Missing levels and readings are not invented.

Shiritori uses the local JMdict dictionary first and may send an unknown word to Jisho for an exact-match fallback (EDRDG dictionary attribution applies). Its thematic categories use approximate English-gloss filters, not a curated taxonomy. Kana input conversion uses WanaKana (MIT).
